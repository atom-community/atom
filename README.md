## What Is Atom-Commuity?

Atom-Commuity is a continuation of the original [Atom Editor](https://github.com/atom/atom); a hackable text editor for the 21st century, built on [Electron](https://github.com/electron/electron), and based on everything we love about editors. Everything is customizable/hackable without limits, but the defaults are designed to get you code.

Visit [atom-community.io](https://atom-community.io/) to learn more about or join us on [Discord](https://discord.gg/fSqg5fRG6R).

## Documentation

If you want to read about using Atom or developing packages in Atom, the [Atom Flight Manual](https://flight-manual.atom.io) is free and available online. You can find the source to the manual in [atom/flight-manual.atom.io](https://github.com/atom/flight-manual.atom.io).

The [API reference](https://atom.io/docs/api) for developing packages is also documented on Atom.io.
